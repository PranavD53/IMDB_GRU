# Movie Review Sentiment Analysis using Deep Learning

This project performs sentiment analysis on movie reviews using Deep Learning techniques. The IMDB Movie Reviews dataset is used to classify reviews as **Positive** or **Negative**. Three sequence-based neural network architectures—**SimpleRNN**, **LSTM**, and **GRU**—were developed, trained, and evaluated to compare their performance on sentiment classification tasks.

The project includes data preprocessing, exploratory data analysis, model training, performance comparison, visualization, and real-time sentiment prediction. Metrics such as Accuracy, Precision, Recall, F1-Score, Validation Loss, and Training Time were used to evaluate the models.

A Streamlit-based web application was developed to provide an interactive user interface where users can enter custom movie reviews and receive sentiment predictions with confidence scores. The dashboard also allows comparison of predictions from all three models on the same review.

### Technologies Used

* Python
* TensorFlow / Keras
* NumPy & Pandas
* Matplotlib & Plotly
* Scikit-learn
* Streamlit

### Features

* Sentiment classification of movie reviews
* Comparison of SimpleRNN, LSTM, and GRU models
* Confidence score visualization
* Real-time prediction dashboard
* Interactive model comparison interface

Among the evaluated models, the best-performing model was selected and deployed for real-time sentiment analysis.
